# Download onto your Mac

The project is available on the `codex/smart-artboard-resizer` branch of `Ayo-deji2000/CODEX`. No merge is required to download it.

## Project ZIP only

1. Open https://github.com/Ayo-deji2000/CODEX/blob/codex/smart-artboard-resizer/output/Smart-Artboard-Resizer.zip in Safari or Chrome.
2. Click the **Download raw file** button (down-arrow icon) on the file toolbar. If GitHub shows **View raw**, click it to download the ZIP.
3. Open Finder > Downloads and double-click `Smart-Artboard-Resizer.zip`.
4. Open the extracted `Smart-Artboard-Resizer` folder, then `docs/INSTALLATION.md`. This Markdown file can be read in TextEdit or any text editor; it is also rendered on GitHub.
5. Keep all project subfolders together. Illustrator needs the shared engine; Photoshop needs every file in its plugin folder.

Direct project ZIP download: https://raw.githubusercontent.com/Ayo-deji2000/CODEX/codex/smart-artboard-resizer/output/Smart-Artboard-Resizer.zip

## Entire branch ZIP

1. Open https://github.com/Ayo-deji2000/CODEX/tree/codex/smart-artboard-resizer.
2. Confirm the branch selector says `codex/smart-artboard-resizer` rather than `main`.
3. Click the green **Code** button, then **Download ZIP**.
4. In Finder > Downloads, double-click the downloaded ZIP. Its extracted repository folder contains `Smart-Artboard-Resizer/`, which contains the project and installation guide.

Direct branch ZIP download: https://github.com/Ayo-deji2000/CODEX/archive/refs/heads/codex/smart-artboard-resizer.zip

These downloads contain the same source project. The complete branch ZIP also includes the original repository README and the separately packaged project ZIP in `output/`.

Adobe application validation is pending. Start with the sample and review `docs/ADOBE-TESTING.md` and `docs/KNOWN-LIMITATIONS.md` before production use.
