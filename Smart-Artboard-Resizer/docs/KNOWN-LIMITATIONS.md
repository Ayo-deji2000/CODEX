# Known limitations

- **Adobe host validation pending.** A successful mock test is not evidence of rendering or successful plugin installation. Test copies before production adoption.
- Geometry infers relationships, not meaning. There is no AI recognition of logos, CTA wording, heading semantics or images. Standalone Illustrator font size is used for small-type warnings, not a guarantee of hierarchy preservation. Large decorative objects can join otherwise unrelated components.
- Section reflow preserves horizontal bands and reading order top-to-bottom, with columns intact. It does not automatically turn arbitrary columns into rows. Complex magazine layouts, diagonal text and tightly layered posters commonly fall back to Safe Fit or need manual adjustment. The Illustrator Analyze report explicitly identifies whole-page root groups and explains when they cannot reflow. Reduce the safe margin to 0% to remove the configured inset; remaining aspect-ratio bands cannot be removed without cropping, stretching, or restructuring the composition.
- Text remains editable. Illustrator can widen isolated simple paragraph frames; Photoshop keeps paragraph-frame dimensions. No reliable automated overset or missing-font audit is implemented; manual checks are required. The 8 pt warning applies only to the simple Illustrator text size that can be read, not all mixed or nested runs. Small text is warned about rather than forcing a geometry-breaking minimum font size.
- Illustrator locks/hidden items and whole groups containing them are skipped. Photoshop canvas copies retain them unchanged; locked/hidden selected-artboard extraction is blocked. These behaviors can cause outputs to omit/misplace/crop content; warnings are explicit.
- Illustrator ownership is geometric. Cross-boundary or multi-artboard intersections require explicit selection. Even wholly contained artwork can belong to another composition; review the analysis and use selection when needed. Threaded text and unrecognized native object types are blocked. Documented PluginItem objects are allowed as atomic native artwork; the script cannot inspect their plugin-managed internals or guarantee that every third-party plugin accepts the operation. A failed native copy/transform rolls back instead of dropping or expanding the object.
- Illustrator root layers are consolidated into one new output layer per artboard. Group internals and root stacking order are kept, but source layer hierarchy, layer-level appearance and cross-layer compositing are not exactly reproduced. Source layers stay intact.
- Illustrator clip bounds use simple clipping paths or compound clipping masks when available; complex masks, opacity masks, effects and symbols may have bounds that differ from painted appearance. Review crops and effects.
- Likely page-sized backgrounds use proportional cover, so bleed extends beyond the target. Illustrator artboards do not clip their surrounding artwork. Background overlap with other artboards is possible despite nonoverlapping artboard rectangles; inspect the pasteboard. A foreground illustration spanning the full page can be misclassified.
- Photoshop selected-artboard output is a separate ordinary canvas. It has no same-document artboard placement/gap or all-artboards batch control. Artboard-only background color, container effects, container metadata and compositing are not recreated. Add an explicit editable background layer before extraction.
- Photoshop extraction uses a read-only descriptor schema with runtime validation. Unsupported artboard rectangles stop rather than use guessed dimensions. Artboard-to-canvas coordinate normalization and cropping need particular attention in host testing. Empty artboards are blocked; empty ordinary canvases can produce a copy containing unchanged layers.
- Ungrouped Photoshop clipping chains/linked layers are blocked. Group complete relationships before converting. Cross-group linked relationships, global adjustments and dependent effects require manual review. Raster layers are resampled in the duplicate, so repeat conversions can reduce image quality; Smart Objects are preferable. No layer is intentionally rasterized, merged or flattened.
- Oversized artwork is fitted proportionally and may become illegible; unknown sources require an explicit target. Missing Illustrator links stop conversion; Photoshop linked Smart Objects and fonts need a manual resource check.
- Predicted collisions and margins use bounding boxes and exclude background bleed. Existing overlap is treated as intentional. Effects and actual font rendering can differ from these predictions.
- Illustrator preview review is a modal dialog, with Keep/Discard and no interactive zoom. Discard removes only generated layers/artboards; the document's dirty/history state may remain changed. It does not use global Undo, which could affect original edits.
- Photoshop preview is a real editable document. Discard intentionally drops all its unsaved edits. Closing/reloading the plugin can lose preview tracking. Kept copies are never automatically saved.
- Ordinary failures roll back generated objects/documents. Photoshop also uses modal auto-close registration. A force-quit, host crash or failed cleanup can leave partial generated copies; source operations are never destructive. Inspect generated `SAR - …` layers/artboards or `Converted - …` documents and remove only those copies.
- Illustrator canvas/artboard-count limits and unsupported Photoshop document modes are not bypassed. Host operations may reject a conversion; a helpful error is shown and cleanup is attempted.
- Reverse conversion is another layout pass, not restoration of the original arrangement. Source documents, artboards and previous copies remain untouched.
